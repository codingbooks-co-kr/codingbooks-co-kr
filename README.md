# 🎨 코딩북스 (CodingBooks)

> *"삶이 예술(Art)이라면 당신은 이미 예술가(Artist)입니다."*  
> **누구나 코딩 아티스트! 코딩북스는 쉽고 즐거운 창작 중심의 코딩 교육 콘텐츠를 만듭니다.**

---

### 📚 주요 출판 및 실습 분야
- **Creative Coding**: p5.js(기초·영상·사운드), Processing 기반 시각 예술 코딩
- **Physical Computing**: 아두이노(Arduino) 코딩쉴드 하드웨어 제어 및 가상/실제 회로 실습
- **융합 실습 교재**: 전공 불문 입문자를 위한 전자책/종이책 및 오픈소스 예제 코드 제공
